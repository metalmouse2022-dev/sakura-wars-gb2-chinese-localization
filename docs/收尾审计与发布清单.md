## 敏感信息、体积和许可

- 未发现明显密钥或私钥标记。
- 在 `bgb/bgb.ini` 发现个人磁盘上的最近 ROM 路径；整个 `bgb/` 已列入忽略规则，配置原件保留。
- `.gbc` ROM、`.sav` 存档、`.ram` 模拟器状态、`.sn*` 快照均不会进入常规 Git 提交。
- 用户确认两款字体均从 GitHub 下载。Ark-Pixel 来自 [TakWolf/ark-pixel-font](https://github.com/TakWolf/ark-pixel-font)，工程内许可文本为 SIL Open Font License 1.1；发布时需保留许可及版权声明。
- 小点阵字体来自 [pixel-font-legacy/xiaodianzhen-pixel-font](https://github.com/pixel-font-legacy/xiaodianzhen-pixel-font)。其上游说明明确表示原始字体来源、作者和版权不明；仓库列出的 MIT 许可是构建程序许可，不足以证明字体文件可再分发。字体文件已从公开提交忽略规则中排除，需先取得明确授权或换用许可清楚的字体。
- 构建脚本使用 Windows 系统宋体，指南说明该字体由操作系统提供，不应复制到仓库。
- 已发现 4MB ROM 和多个约 5MB 字体文件。ROM 排除；仅纳入构建所需的简体中文 Ark-Pixel 字体及 OFL 许可文本，其余语言变体排除。
