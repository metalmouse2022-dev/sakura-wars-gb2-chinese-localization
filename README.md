## 构建状态

从工程根目录运行 `python build_all.py` 是预期的一键构建入口；脚本会创建 `outputs/` 目录。构建需要 Pillow、zhconv、与脚本预期版本一致的日版原始 ROM，以及所需字体文件。ROM 不随仓库分发。

当前公开副本未包含原版 ROM；由于小点阵字体的原始字形版权来源不明，其字体文件也不随仓库分发。因此，克隆后还不能直接完成全量构建。请先阅读汉化者指南中的输入要求和许可说明，不要将 ROM、存档或未授权字体提交到仓库。

## 许可

本仓库尚未声明整体许可证。第三方字体按各自上游许可证处理；游戏 ROM 和游戏原文/译文也不属于可由本项目自行授权的内容。请勿将仓库内容理解为 Sega 或原权利人授权的官方发行。
